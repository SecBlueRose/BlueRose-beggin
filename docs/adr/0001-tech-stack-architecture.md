# ADR 0001: Selection of Core Tech Stack & Repository Architecture

* **Status:** Accepted
* **Date:** 2026-09-01
* **Author:** Khan Konstantin

---

## Context
Для реализации DevSecOps-платформы Aegis требуется выбрать масштабируемый стек технологий, который позволит покрыть задачи системного программирования, автоматизации ИБ, написания CLI и создания наглядного UI.

---

## Decision
Принято решение использовать монорепозиторий со следующим разделением ответственности по языкам и технологиям:

1. **Go (Golang):**
   * *Role:* Разработка CLI-клиента (`aegis-cli`) и основного Core REST API Gateway.
   * *Rationale:* Высокая производительность, статическая типизация, компиляция в один бинарник, стандарт де-факто в Cloud Native (Docker, K8s).

2. **Python:**
   * *Role:* Security Engine (парсинг логов, запускалка SAST/SCA сканеров, генератор отчетов).
   * *Rationale:* Богатая экосистема библиотек для работы с данными, парсинга и скриптов ИБ.

3. **Bash / Shell:**
   * *Role:* Автоматизация развертывания, скрипты инициализации (Bootstrap), Git-хуки, CI/CD.
   * *Rationale:* Нативный язык администрирования Linux-систем.

4. **Web UI (Frontend):**
   * *Role:* Плотный, эргономичный дашборд в стиле JetBrains IDE (Darcula Theme).
   * *Evolution:* Легковесный HTML5/CSS на старте с потенциальным переходом на React/TypeScript при усложнении UI.

---

## Consequences
* **Positive:** Покрытие ключевых стеков DevSecOps-инженерии; четкая изоляция сервисов; удобный локальный деплой.
* **Negative:** Необходимость поддерживать несколько средовых окружений (Go toolchain, Python venv) в одном репозитории.
